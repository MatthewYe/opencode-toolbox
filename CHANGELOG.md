# Changelog

## [1.0.0] — Initial release

- **Autopilot workflow**: `/autopilot` command with implementer → reviewer TDD loop, up to 3 retry rounds
- **Agents**: `implementer` (TDD execution) and `reviewer` (3-axis read-only review)
- **Engineering skills** (from mattpocock/skills): `tdd`, `diagnose`, `triage`, `to-issues`, `to-prd`, `zoom-out`, `grill-with-docs`, `improve-codebase-architecture`, `prototype`, `setup-matt-pocock-skills`
- **Productivity skills** (from mattpocock/skills): `caveman`, `grill-me`, `handoff`, `write-a-skill`
- **Custom skills**: `skill-creator` (eval-driven skill development), `opencode-plugin-scaffold` (create/fix OpenCode plugins)
- **Plugin auto-discovery**: `.md` files with YAML frontmatter auto-register as agents/commands; skill paths registered via config hook
